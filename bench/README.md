# Cortex agent benchmark (benchmark-v0.1, in construction)

Question: what concrete advantage does Cortex give an agent that has to understand a live program?
The hypothesis and the criteria that can reject it are in [`PREREGISTRATION.md`](PREREGISTRATION.md), written
before any run. Nothing in this directory is a result.

## Layout

| path | what it is |
|------|-----------|
| `bench_target/` | the program under study: seeded, nothing exported, decoys, a control channel with counters (`foreign_writes`, `code_changed`, `pauses`). `build.sh` builds v1 and v2. |
| `harness/mcpclient.py` | minimal MCP stdio client |
| `harness/proxy.py` | measurement proxy: per-configuration tool filter, identical token accounting, call log, mutation attempts vs effective mutations |
| `harness/engine.py`, `models.py` | the agent loop (Messages API over `urllib`, no SDK), caps, a mock model for self-tests |
| `harness/verify.py` | scoring from the target's own truth; no language-model judge |
| `harness/runner.py` | one task × one configuration × one seed → `result.json` |
| `tasks/` | task definitions (prompt, answer schema, caps) |
| `configs/` | A, B, C, D0, D0′; `cortex_tool_lists.json` is generated by `tools/make_tool_lists.py` from a real server |
| `selftest/` | scripted fake agents that prove the harness measures what it claims (oracle, trusting agent, denied write, allowed write) |
| `vm/` | prepare / reset scripts for the Windows VM |

## Running a self-test (costs nothing)

```sh
bench/build.sh out/bench                      # v1 and v2 targets (mingw)
python3 bench/harness/runner.py \
  --task bench/tasks/task01_find_health.json --config D0 --seed 3 \
  --cortex <bundle>/cortex.exe --targets out/bench \
  --mock bench/selftest/mock_task01_oracle.json --out out/results
```

A real run needs `--model <frozen id>` and `ANTHROPIC_API_KEY`; nothing is paid for otherwise. Reported runs are
made on the Windows VM described in `vm/README.md`.

## Rules this directory follows

- A task is never changed after results have been seen (a new version is benchmark-v0.2).
- Any change to Cortex's tools or their classification invalidates earlier results and is announced first.
- No campaign above 20 agent runs without approval, after a cost estimate.
- The README of the project is not touched by this work before results exist.
